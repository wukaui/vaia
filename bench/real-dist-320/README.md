这里只放**这一轮几个数的汇总产物**，不放样本、不放逐文件原始行。

| 文件 | 是什么 |
|---|---|
| `summary.json` | `scripts/real_dist_summary.py` 的输出：①层那一臂（送审率 / 结案率 / 召回 / 耗时 / 核验）+ 对照臂（**全量实测** + **抽样实测**）+ **外推**块 + 生产档实际 token + **摘掉 ClamAV 那 1000 分的消融** |

**每个块都带 `kind` 字段**：`measured` = 实测，`extrapolated` = 外推，`derived` = 由两者算出。
**外推的数不许当实测值用**（"全部送 AI"那一列就是外推）。

## 对照臂的口径（2026-09-27 变更："抽样吧"）

对照臂**不再全量跑** —— 全量跑一遍是 2.2M token / 41 分钟，而"每文件均值"这个数抽样就能拿到。

- **正式口径**：分层抽 **48** 个（`seed=20260927`，分层 = `类别 × 来源池`，恶意占比与语料一致 = 6.25%）
  → 算每文件均值 → **按规模外推**（外推值单列，不与实测混排）。
- **历史那一轮不推翻**：对照臂在补充指令到达前**已经全量跑完**（319 个文件 / 273 个出 AI 结论 /
  2,195,054 token），原样当**实测参照**留着；抽样口径与它的偏差 **−0.16%**
  （见 `summary.json` 的 `ai_arm_sampled.sampling_check_vs_full_run`）。
- 改这一版**没有再调一次模型**（0 token）—— 抽样的逐文件实测值就是从上面那一轮的产物里读的。
